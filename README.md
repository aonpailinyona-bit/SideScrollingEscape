# SideScrollingEscape

เกม 2D Side Scrolling พัฒนาด้วย Unity Engine

## การเปิดและรันโปรเจกต์ (How to Open and Run)

1. เปิดโปรแกรม **Unity Hub**
2. เลือก **Add** -> **Add project from disk**
3. เลือกโฟลเดอร์: `SideScrollingEscape` (โฟลเดอร์โปรเจกต์ด้านในที่มี `Assets`, `Packages`, `ProjectSettings`)
4. **Unity Version**: แนะนำใช้เวอร์ชัน **Unity 6 (6000.4.9f1)** หรือเทียบเท่า
5. เปิดฉากเริ่มต้น: `Assets/Scenes/MainMenu.unity` หรือ `Level1.unity` แล้วกด **Play**

## โครงสร้างโปรเจกต์ (Project Structure)
- `SideScrollingEscape/`: โฟลเดอร์โปรเจกต์เกม Unity หลัก (Assets, Sprites, Scenes, Prefabs, Scripts)
- `chapter3_work/`: เอกสาร แผนผัง ไดอะแกรม และสรุปงานบทที่ 3
- `artifacts/`: รายงานการตรวจสอบสถานะเกม (Validation reports)
